# Testing Checklist

| ID | Test | Expected Result |
|---|---|---|
| T01 | Start application with valid setup | Main menu appears |
| T02 | Enter invalid main-menu choice | Program asks again |
| T03 | Enter unknown student ID | Student login is rejected |
| T04 | Enter malformed date | Program asks for DD-MM-YYYY |
| T05 | Book a past date | Booking is rejected |
| T06 | Use slot outside 1-6 | Booking is rejected |
| T07 | Create a valid booking | PENDING booking is created |
| T08 | Create same student/date/slot booking again | Duplicate is rejected |
| T09 | Approve pending booking as staff | Status becomes CONFIRMED |
| T10 | Reject pending booking as staff | Status becomes REJECTED |
| T11 | Cancel own pending/confirmed booking | Status becomes CANCELLED |
| T12 | Put resource under maintenance | Future bookings requiring it are blocked |
| T13 | Complete maintenance | Resource becomes AVAILABLE |
| T14 | Export booking report | CSV file is generated |
| T15 | Run backup | Backup file is generated by a background thread |
